`openclaw setup`

Initialize `~/.openclaw/openclaw.json` and the agent workspace.

- Wizard: [Onboarding](/start/onboarding)

```
openclaw setup
openclaw setup --workspace ~/.openclaw/workspace

```

```
openclaw setup --wizard
```
